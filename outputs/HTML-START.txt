BALTONA — OBSŁUGA USTEREK / WERSJA HTML

1. W pliku Baltona-Usterki.html uzupełnij `SUPABASE_URL` oraz publiczny `SUPABASE_ANON_KEY`.
2. W Supabase Authentication → Users utwórz użytkowników. Rolę ustaw w User metadata jako `role`: `Użytkownik`, `Koordynator` lub `Administrator`.
3. W Supabase Authentication → URL Configuration dodaj adres GitHub Pages do Site URL i Redirect URLs.
4. Otwórz Baltona-Usterki.html w zwykłym oknie Edge lub Chrome.
3. Zgłoś usterkę i dodaj JPG, PNG lub PDF. Dane zapisują się w tej przeglądarce.
4. Przełącz na koordynatora, aby przypisać osobę, ustawić termin i status.
5. W Administracja → Raporty i kopia danych pobierz pełną kopię JSON.
6. Dzwonek pokazuje nieprzeczytane powiadomienia danego profilu. Kliknięcie wiadomości otwiera zgłoszenie.
7. Nowe zgłoszenia, komentarze i zmiany danych obsługi powiadamiają autora zgłoszenia i centralę, z wyjątkiem osoby wykonującej działanie.
8. Drugą kartę otwórz pod identycznym adresem — dzięki temu korzysta z tej samej bazy. Powiadomienia i dane odświeżają się automatycznie; niezapisany formularz nie jest nadpisywany.

WAŻNE
- Logowanie i sesja są obsługiwane przez Supabase Auth.
- Zgłoszenia i załączniki nadal zapisują się lokalnie w tej wersji HTML; baza Supabase nie przechowuje ich automatycznie.
- E-maile i Teams nie są wysyłane. Alerty widać w otwartej aplikacji.
- Sam plik HTML zawiera początkową listę obiektów, lecz nie późniejsze zgłoszenia.
- Kopia JSON zawiera zgłoszenia, komentarze, powiadomienia, profile, konfigurację i załączniki.
- Przed czyszczeniem przeglądarki lub zmianą adresu/komputera pobierz kopię.
- Dane zapisane w lokalnym podglądzie i w pliku otwartym dwuklikiem są odrębne.
- Nie używaj trybu prywatnego do trwałego przechowywania danych.

Lista startowa: 67 lokali i 5 magazynów. MPK 206 jest nieaktywny.
Przy pierwszym otwarciu nie ma przykładowych zgłoszeń.
Wybierz „Zamknij zgłoszenie” lub „Odrzuć zgłoszenie”, aby wyświetlić wymagany komentarz, a następnie potwierdź akcję.
Koszt naprawy został usunięty z formularzy, podsumowań i eksportu CSV. Wcześniej zapisane kwoty pozostają wyłącznie w kopii JSON dla zgodności danych.
